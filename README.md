# DevLift — AI-Powered Developer Onboarding Accelerator

> Understand any codebase in 60 seconds. Powered by IBM watsonx.ai.

Built for the **IBM Bob Hackathon** — "Turn idea into impact faster"

---

## What It Does

DevLift eliminates the painful days a new developer spends figuring out an unfamiliar codebase. Paste any public GitHub URL and get a structured **Onboarding Kit** generated by IBM watsonx.ai in under 90 seconds.

**Two modes:**

| Mode | What happens |
|------|-------------|
| 🔗 Analyze a repo | Paste a GitHub URL → get a full onboarding kit |
| ✦ Discover repos | Describe your stack → get curated repo matches + kits |

---

## Onboarding Kit Sections

1. **Architecture Overview** — What the codebase does and how its layers interact
2. **Key Components** — The 7 most important files a new developer must understand
3. **Complexity Hotspots** — Risky or tricky areas with actionable tips
4. **Suggested First Tasks** — Starter contributions sorted by difficulty (easy/medium/hard)
5. **Common Patterns** — Code conventions and idioms used throughout
6. **Setup Guide** — Prerequisites, install steps, run and test commands

**Plus: Contribution Readiness Score** — A 0–100 grade measuring how contributor-friendly the repo is across documentation, test coverage, CI/CD automation, complexity, and community health.

## Running Locally

### Prerequisites
- Node.js >= 18
- Python >= 3.11
- IBM Cloud account with watsonx.ai access
- GitHub personal access token

### Backend

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate   # Mac/Linux
pip install -r requirements.txt
```

Create `backend/.env`:
```
GITHUB_TOKEN=your_github_token
WATSONX_API_KEY=your_watsonx_api_key
WATSONX_PROJECT_ID=your_project_id
WATSONX_URL=https://us-south.ml.cloud.ibm.com
```

```bash
uvicorn main:app --host 127.0.0.1 --port 8001
```

### Frontend

```bash
cd frontend
npm install
```

Create `frontend/.env.local`:
```
NEXT_PUBLIC_API_URL=http://localhost:8001
```

```bash
npm run build && npm start
```

Visit `http://localhost:3000`

## API Endpoints

### `POST /analyze`
```json
{ "repo_url": "https://github.com/owner/repo" }
```
Returns full onboarding kit + readiness score (~60–90s).

### `POST /recommend`
```json
{ "requirement": "I want to build a REST API with Node.js and TypeScript..." }
```
Returns 3–5 ranked repo suggestions with explanations (~15–25s).

### `GET /health`
Returns `{ "status": "ok", "model": "meta-llama/llama-3-3-70b-instruct" }`
