## 🐛 Troubleshooting

### Import errors in VSCode?
**Normal!** They'll disappear after dependencies install. The code will run fine.

### Backend won't start?
1. Check Python version: `python --version` (need 3.11+)
2. Reinstall: `cd backend && pip install -r requirements.txt`

### Frontend won't start?
1. Check Node version: `node --version` (need 18+)
2. Reinstall: `cd frontend && npm install`

### API key not working?
1. Make sure you replaced the placeholder in `backend/.env`
2. Verify IBM Cloud account has watsonx.ai access
3. Check project ID is correct
